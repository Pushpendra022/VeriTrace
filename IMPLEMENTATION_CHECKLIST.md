# VeriTrace implementation checklist

This checklist mirrors the required implementation order in `README.md`. A phase is complete only after relevant tests pass and both applications still start.

- [x] Phase 1 — Foundation: React/Vite, FastAPI, configuration, SQLite, Alembic, health, visual system, navigation, and routes.
- [x] Phase 2 — Upload validation, secure temporary extraction, page persistence, and document viewer.
- [x] Phase 3 — Page-aware chunking, TF-IDF retrieval, relevance boosts, and diagnostics.
- [x] Phase 4 — Manual claim CRUD and Gemini-backed structured extraction.
- [x] Phase 5 — Provider abstraction, Gemini/mock providers, schemas, deterministic checks, and conflict resolution.
- [x] Phase 6 — Quote validation, offsets, page navigation, and evidence highlighting.
- [x] Phase 7 — Multi-claim review, filters, sorting, controlled concurrency, and selected verification.
- [x] Phase 8 — Persistent history, reopen, rerun, summaries, and deletion.
- [x] Phase 9 — Supabase PostgreSQL, Render, Vercel, production CORS, and deployment configuration.
- [x] Phase 10 — Backend/frontend tests, 22-case dataset, evaluation script, and measured results.
- [x] Phase 11 — Accessibility and responsive audit, operational states, retention cleanup, documentation review, and code cleanup.
